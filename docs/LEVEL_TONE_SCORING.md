# 平调词（一声）评分反向 —— 调查报告

排查 `ReferenceShapingTests.testRealTTSReferenceForLevelWordIsNotStronglyFalling`
在 `main` 上失败时发现的更深层问题。**结论：一声词的 DTW 评分方向是反的。**

## TL;DR

一声词读得越平，分数越差；读成明显下滑，反而通关且分数更高。
语料 20 条里 **11 条（55%）含一声**，其中「医生」「参加」为全一声。
**任何含一声词的 DTW 分数都不可信**，这会影响已收集数据的可用性。

## 一、原始症状：一个测不出东西的测试

`testRealTTSReferenceForLevelWordIsNotStronglyFalling` 断言 1+1 词参照线
首末落差 > -1.2 sd，实测 -1.33 失败。逐级拆解「参加」：

| 阶段 | 绝对落差 | SD | drop/SD |
|---|---|---|---|
| clean（原始 TTS） | -15.66 Hz | 7.83 | -2.00 |
| detrend（去下倾） | **-4.48 Hz** | 4.36 | -1.03 |
| blend（混合理想） | -4.44 Hz | 3.34 | **-1.33** ← 失败 |
| *理想轮廓自身* | *-4.17 Hz* | *3.74* | *-1.12* |

- **去下倾其实有效**：绝对落差削掉 72%，在 265 Hz 均值上仅 0.28 个半音。
- **测试的指标测不出这件事**。`ReferenceShapingTests` 顶部 `dropHz` 的注释
  自己写明：「归一化后的趋势对纯直线是尺度不变的……量不出『下倾被削平』这件事」。
  文件里其它测试都用裸 Hz，唯独这个集成测试用了 z——因为
  `synthesizeReferenceF0` 只返回归一化结果，它没得选。
- **残余下滑主要来自 `ToneContour` 自身**：T1 定义为 `270 - 12t²`，
  每音节降 12 Hz 且第二音节重置回 270，拼成锯齿，自身 drop/SD 已达 -1.12，
  贴着 -1.2 阈值，管线没有余量。混合还会过冲（-1.03 → -1.33），
  因为它抵消的是纹理方差、保留的是单调漂移。

> 附带：「z 域混合」这条路走不通，会打挂 `testBlendPullsShapeTowardIdeal`。
> 原作者注释里已预判并否决，是对的。

## 二、真正的问题：z-score 对平调是退化的

`F0Extractor.normalize` 做 z-score per utterance（CLAUDE.md 锁定参数）。
对有真实音高走势的声调没问题；**对平调是除以一个接近零的 SD**，
把微观抖动放大成满量程形状。

实测（1+1 参照，候选发音叠加不同词级落差）：

| 词级落差 | DTW | 结果 |
|---|---|---|
| 0 Hz（读对，完全平） | 0.501 | ❌ 差 0.001 不通关 |
| +10 Hz | **0.324** | ✅ 最优 |
| +45 Hz（明显读错） | 0.379 | ✅ 通关 |
| +80 Hz（几乎成去声） | 0.355 | ✅ 通关 |

抖动敏感性同样说明问题：完美平读时 ±1 / ±2 / ±5 / ±10 Hz 抖动
**DTW 全部等于 0.934**——z-score 把幅度彻底抹掉，只剩无意义的微观图案在比对。
而抖动 ±0（音高绝对平稳）时 SD=0，`normalize` 返回全 0 序列，DTW = **9.99**，
即最稳的学习者拿最差分。

4+4 去声对照组最优解落在 0 Hz、DTW 0.081，方向完全正常——
问题只出在低方差的平调。

## 三、显示层是同一个病根

`displayReference` 画给学习者看的就是这条归一化曲线，
所以一声词的目标线在屏幕上必然明显下降。
且 `ToneTrainingViewModel:97` 的 TTS 回退路径用同一个 `ToneContour.ideal`——
**即使完全不走 TTS，1+1 的目标线照样是斜的。**

## 四、候选修法（已验证，未采纳）

带下限的 z-score：`z = (x - mean) / max(sd, floor)`，floor 取 8 Hz。

| 词级落差 | 现行 | floor=8 |
|---|---|---|
| 0 Hz（读对） | 0.501 ❌ | **0.151 ✅** |
| +10 Hz | 0.324 ✅ | 0.151 ✅ |
| +60 Hz | 0.329 ✅ | 0.329 ✅ |

- **4+4 逐位不变**（0.081/0.084/0.087… 完全一致）：高方差声调不受影响，
  现有校准与历史数据可比性得以保留。
- 1+1 最优解回到「平」，**反向被纠正**。
- 局限：大幅下滑仍能通关，因为理想轮廓自身带下倾且 0.5 通关线偏宽。
  要一并收紧，需同时处理 `ToneContour` 的 T1 锯齿或为平调单设阈值。

⚠ **未实施**：CLAUDE.md 把「归一化方式 = z-score per utterance」与
「通关线 ≤ 0.5」列为不可变更的核心约束，改动需先决策。

## 五、对研究数据的影响

- 含一声词的既有 DTW 分数、等级、通关状态**不能**作为发音正确性的证据。
- 若修改归一化，`schemaVersion` 必须递增，且修改前后的分数**不可混合分析**。
- 相关特征测试见 `PinYintoneTests/Audio/LevelToneScoringProbe.swift`
  （断言的是现状缺陷，修好后需反向改写）。
