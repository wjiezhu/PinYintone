## 一、已确定

| # | 事项 | 决定 |
|---|---|---|
| 1 | 三阶段流程 | 降级为**用户主动发起的可选自测**；字段字典需补 `task_type = self_test` |
| 2 | 词卡 | 作为「推荐练习」入口：可随时退出、也可自己挑词 |
| 3 | 练习模式 | 每词 3 次机会；说对→积分→下一词；3 次用完自动过 |
| 4 | 自测模式 | **纯裸测**：每词录一次自动过，不发积分、不设机会，共用词卡 UI 但隐藏分数/积分/机会计数 |
| 5 | 词集重叠 | 接受重叠；自测记录带「该词此前练过几次」（复用 `ToneAttemptStore`） |
| 6 | 「说对」判定 | `grade != fail`，**含平调词走向闸门**；不可只看 DTW ≤ 0.5 |
| 7 | 技术失败 | **不消耗**机会次数 |
| 8 | 积分粒度 | 每词**首次**说对才给；解锁**额外**词包，基础词库永不上锁 |
| 9 | 新旧数据 | **新建独立研究表**，旧表冻结只读；不靠「记得加过滤条件」 |
| 10 | 教师看板 / 班级码 | 不进新版，冻结归档 |
| 11 | 送气练习（关卡 1） | 保留可用，**不进研究数据**（字典 `task_type` 无此类型） |
| 12 | 参考音 | 先修算法（轻声语境、三声变调），教师核对放到总结阶段 |
| 13 | 用户编号 | 服务端 `user_id`，按 Apple ID 归并；研究库另用随机 `participant_id`，经受限映射表关联 |
| 14 | AI 建议 | 先只做固定模板（`source_type = rule_feedback` / `teacher_hint_only`） |
| 15 | 一声诊断 | 改由 `ToneDirectionGate` 半音实测值驱动，不再无证据断言 |
| 16 | 自由文本 | 标记「声调标注系自动推定、未经核对」；补平调词走向闸门 |
| 17 | 录音存储 | 只留当前一条，供本次回听；换词/重录即覆盖，退出即清 |
| 18 | 问卷触发 | 5 次（词库练习分析成功且结果已显示；同词重录可累计；不要求通过；自由文本不计入） |
| 19 | HSK 范围 | **HSK1 / HSK2 / HSK3**（以三份研究文档为准，非最初需求的 HSK2/3） |
| 20 | 旧用户识别 | 以旧库 `users.apple_user_id` 命中判定为 `returning`（证据 `verified_account_history`）；未命中记 `new` 但证据 `insufficient` |

### 由字典直接约束、无需再议的

- **哨兵 `-1` 不带进新表**：`metric_value` 可空，无观测值写 `NULL`（字典禁止虚构默认值）
- **轻声编码改用 `0`**：现有代码与语料用 `5`，须随新表统一为字典的 `citation_tones` 约定
- **端侧筛选是硬要求**：同意与资格门禁必须在客户端实现，后端不得先全量收集再导出时过滤
- **采集窗口统一 14 天**（左闭右开），非每人 14 天
- 积分：研究库只记 `research_reward_events` 发放事件；余额与解锁属业务侧，不进研究库
